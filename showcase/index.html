04 / SECURITY BY DESIGN

Secrets require real security controls.

Kubernetes Secret data is Base64-encoded by default, not automatically encrypted. Production environments need appropriate encryption at rest, least-privilege RBAC, restricted access, and credential rotation.

✓ Avoid committing credentials to Git ✓ Apply least-privilege RBAC ✓ Configure encryption at rest ✓ Consider external secret managers
